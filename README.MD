### 📌 Project Overview
This dashboard was built to help Vrinda Store track revenue, profit, and country-wise performance for data-driven decisions. It consolidates multiple pivot tables and charts into a single executive view.

### 📊 Visuals in this Dashboard
1.  **Revenue and Profit by Month:** Line chart showing trend. Revenue peaks at ₹70K in June and ₹66K in July, profit stays stable at ₹29K-₹31K.
2.  **Top 5 Country by Revenue:** UK (₹74K) is top, followed by Germany (₹70K), France (₹55K), Italy (₹50K), Spain (₹47K).
3.  **Revenue Share by Channel:** Corporate, Marketplace, Online Store, Retail Partners.
4.  **Revenue Wise Comparison:** By Europe Region - Central, Northern, Southern, Western.
5.  **Country Wise Map Chart:** Geographical distribution of revenue.

**Filters / Slicers:** Product Category, Country, Quarter - Fully interactive.

### 🛠️ Tools Used
- MS Excel | Power Pivot | DAX
- Pivot Tables & Pivot Charts (Line, Bar, Pie, Donut, Map)
- Slicers, Timeline, Custom Formatting: `₹#,##0,"K"`
- Buttons: All Pivot Tables | Sales Data

### 💡 Business Insights
- United Kingdom drives maximum revenue.
- Q2 and Q4 are strongest quarters.
- 45.94% gross margin indicates healthy profitability.

### 📂 How to Run
1. Download `Vrinda Store Sales Dashboard.xlsx`
2. Go to `Dashboard` sheet
3. Use slicers on right to filter.
